# 📋 Comment Obtenir le Template ID EmailJS

## 🔍 Étapes pour trouver le Template ID

### 1️⃣ Connectez-vous
Aller sur : https://dashboard.emailjs.com/admin

### 2️⃣ Accéder aux Templates
1. Cliquer sur **"Email Templates"** dans le menu latéral
2. Vous verrez une liste de tous vos templates

### 3️⃣ Trouver le Bon Template
- Cherchez le template que vous venez de créer
- Le **Template ID** est affiché sous le nom du template
- Format : `template_xxxxxxxxx` (par exemple : `template_abc12345`)

### 4️⃣ Copier le Template ID
- Le Template ID est généralement à côté du nom du template
- Ou cliquez sur le template pour voir les détails
- L'ID complet s'affichera dans l'URL ou dans les détails

## 🆘 Si vous ne trouvez pas le Template

### Option 1 : Créer un nouveau template
1. **Email Templates** → **Create New Template**
2. Donner un nom (ex: "SenHarvest Contact")
3. Configurer le template (voir EMAILJS_FIX_412.md)
4. **Save** - Le Template ID sera généré

### Option 2 : Utiliser un template existant
- Ouvrez n'importe quel template existant
- Notez son Template ID
- Modifiez-le pour qu'il corresponde à vos besoins
