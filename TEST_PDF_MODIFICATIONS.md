## 🧪 Comment Tester

### Étape 1: Accéder à l'Interface Admin
1. Ouvrez http://localhost:3000
2. Cliquez plusieurs fois sur le logo SenHarvest en bas de page pour accéder à l'admin
3. Ou naviguez directement vers http://localhost:3000/#/admin

### Étape 2: Créer un PDF Test
1. Dans l'interface admin, sélectionnez "Proforma" ou "Quotation"
2. Remplissez les informations de base :
   - Numéro du document
   - Informations client
   - Ajoutez au moins un produit avec quantité et prix

### Étape 3: Générer et Vérifier le PDF
1. Cliquez sur "Generate PDF" ou "Télécharger PDF"
2. **NOUVELLES CORRECTIONS APPLIQUÉES** - Vérifiez que le PDF généré contient :
   - ✅ Les nouvelles informations d'entreprise dans le footer
   - ✅ "SenHarvest Group — www.senharvest.com" au lieu de "Generated by..."
   - ✅ **AUCUN bouton d'impression visible dans le PDF** (supprimé physiquement)
   - ✅ **AUCUN "about:blank" dans le footer** (supprimé automatiquement)
   - ✅ Aucun élément d'interface utilisateur indésirable

### Étape 4: Test d'Impression - AMÉLIORÉ
1. Ouvrez le PDF généré
2. Utilisez Ctrl+P (Cmd+P sur Mac) pour imprimer
3. **RÉSULTAT ATTENDU** : Seul le contenu du document s'affiche, **AUCUN** élément d'interface
4. Testez aussi la prévisualisation HTML (si disponible) - elle devrait aussi être propre
