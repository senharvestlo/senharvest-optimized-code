# 🔐 Variables d'Environnement Netlify - EmailJS

## 📋 À ajouter dans Netlify

Aller sur : https://app.netlify.com/sites/[votre-site]/configuration/env

### Ajouter ces 3 variables :

```
REACT_APP_EMAILJS_SERVICE_ID = service_pntmtmn
REACT_APP_EMAILJS_TEMPLATE_ID = template_1sh586m
REACT_APP_EMAILJS_PUBLIC_KEY = oa2dvrH8lCJf974vD
```

## 🚀 Étapes

1. Ouvrir https://app.netlify.com/
2. Sélectionner votre site **senharvest**
3. Aller dans **Site settings** → **Environment variables**
4. Cliquer sur **Add a variable** (3 fois)
5. Ajouter chaque variable une par une
6. Cliquer sur **Save**
7. Aller dans **Deploys**
8. Cliquer sur **Trigger deploy** → **Deploy site**

## ✅ Vérification

Après déploiement, tester le formulaire sur www.senharvest.com/contact
